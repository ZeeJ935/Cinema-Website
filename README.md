# 🎬 Cinema Website  

Built with **HTML**, **CSS**, **PHP**, and **JavaScript**, this website provides an interactive platform for browsing movie listings, showtimes, and bookings, utilizing **XAMPP** for backend services and database management.  

---

## **🚀 Features**  
- 🎥 **Browse Movie Listings** – View available movies.  
- ⏰ **View Showtimes** – Check schedules and timings.  
- 🎟️ **Book Movie Tickets** – Secure your seat online.  
- 🛠️ **Backend Powered by PHP & MySQL** – Runs on **XAMPP** for local hosting.  

---

## **🔧 Installation & Setup**  

### **Prerequisites**  
Before you begin, ensure you have the following installed:  
- 📌 [XAMPP](https://www.apachefriends.org/) (for Apache & MySQL)  
- 📌 [PHP](https://www.php.net/downloads) (included in XAMPP)  
- 📌 A Web Browser (Google Chrome, Firefox, etc.)
